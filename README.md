# Jade Play — site de download

Site estático (GitHub Pages) para baixar o **Jade Play**, player de IPTV para Android e Android TV.

- Site: https://juniorschon.github.io/jadeplay/
- Downloads (APK): aba **Releases** deste repositório — o link
  `https://github.com/JuniorSchon/jadeplay/releases/latest/download/JadePlay.apk`
  sempre aponta para a versão mais recente.

O Jade Play não fornece nenhum conteúdo: o usuário precisa de uma lista própria de um provedor autorizado.
